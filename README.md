# 🚙 ジムニーで行く 会津・磐梯山 ⇄ 松川浦 スマホナビツアーガイド

2026年10月16日(金)〜10月17日(土)に実施する、スズキ ジムニーによる1泊2日ツアースケジュールのスマートフォン専用Webガイドです。

- **📱 公開Webガイド (GitHub Pages)**: [https://michu3.github.io/jimny-tour-guide/](https://michu3.github.io/jimny-tour-guide/)
- **📥 カレンダー一括取込ファイル (.ics)**: [jimny_tour_20261016.ics](https://michu3.github.io/jimny-tour-guide/jimny_tour_20261016.ics)
- **出発地 / 帰着地**: 神奈川県川崎市高津区子母口（目標帰着: 10/17 18:00頃）
- **移動車両**: スズキ ジムニー（満タン航続距離：約400km / ENEOS下道満タン戦略）
- **宿泊先**: 磐梯名湯リゾート ボナリの森（中ノ沢温泉）

---

## 🌟 特徴

- **ワンタップGoogle Mapsナビ**: 各チェックポイントの専用ボタンをタップするだけで、現在地から即座に経路ナビゲーションが起動。
- **親指特化型ボトムバー**: 運転席や停車時に片手で操作できるよう、画面最下部に「次の目的地」のナビボタンが常時固定。
- **全体ルートグラフィック**: 会津若松（七日町通り）・裏磐梯から太平洋（松川浦）、首都圏（川崎）への行程が一目でわかるSVG全体イメージ図。
- **カレンダー連携（Googleカレンダー直通 ＆ `.ics` 一括取込）**: 各スポットのワンタップGoogleカレンダー登録および全14枠の一括 `.ics` インポートに対応。
- **ENEOS指定給油マネジメント**: 往路・復路の下道セルフ満タン給油スポット（野口記念館SS、相馬バイパス店）を明記し、高価な高速SA給油ゼロで走破。
- **松川浦 海鮮ランチセレクター**: 当日の気分や混雑状況に合わせて「くぁせっと」「齋春」「たこ八」から選べるワンタップ切り替え。

## 📱 スマートフォンでの推奨利用方法

1. Safari（iOS）または Chrome（Android）で [https://michu3.github.io/jimny-tour-guide/](https://michu3.github.io/jimny-tour-guide/) を開きます。
2. 共有メニューから **「ホーム画面に追加」** を選択します。
3. ホーム画面のアイコンから起動すると、アドレスバーのない全画面Webアプリとして快適に利用できます。
